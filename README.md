# Puddle marketplace

A marketplace project using Django.

## Requirements

* Python 3.13

### Clone and open the repo

```shell
$ git clone repo_https puddle [TODO]
$ cd puddle
```

#### Install Python using uv

1. Download and install uv from [here](https://docs.astral.sh/uv/getting-started/installation/)
2. install python using the following command

```shell
$ uv python install 3.13
```

3. Initialize the project:

```shell
$ uv init
```

### Installation

Install the required packages and sync uv settings

```shell
$ uv sync
```

### Setup the environment variables

```shell
$ cp .env.example .env
```

Set your environment variables in the `.env` file.
